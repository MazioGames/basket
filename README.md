# basket

Un gioco di pallacanestro arcade 2D per browser e dispositivi mobili sviluppato in HTML5 e Phaser 3.

## 🎮 Caratteristiche del Gioco
- **Controlli Touch per Mobile:** Pulsanti virtuali a schermo adattati per smartphone e tablet.
- **Tiro in Parabola:** Caricamento della potenza di tiro con traiettoria visibile in tempo reale.
- **Meccanica Schiacciata (Dunk):** Se ci si trova vicini a canestro, premendo il pulsante di tiro si esegue una schiacciata acrobatica.
- **Timer dei 24 Secondi:** Regolamento dei 24s con reset al tiro o al canestro.
- **Difensore IA:** Giocatore avversario che marca l'attaccante e contesta i tiri con stoppate.

## 🚀 Come giocare online tramite GitHub Pages
1. Vai su **Settings** del tuo repository GitHub.
2. Clicca su **Pages** dal menu laterale.
3. Seleziona la sorgente **Deploy from a branch** e scegli `main` / `root`.
4. Salva: il tuo gioco sarà raggiungibile all'indirizzo `https://tuo-username.github.io/nome-repo/`.
